## Purpose

This matrix defines the denominator for Universal Coding Memory evidence. It is
an inventory and proposed contract, not an accepted ADR or architecture
baseline. A PoC is blocked when its applicable interfaces are absent from this
matrix or the generated inventory.

The deterministic source inventory is
`.aiwg/reports/g-icm-01-interface-inventory.json`, generated by
`npm run evidence:interfaces`. The current candidate tree contains:

- 135 REST routes: one explicitly public liveness route and 134 protected
  routes;
- six MCP HTTP routes, 59 tools, five resources, three prompts, and seven
  reduced standalone fallback tools;
- 13 packaged lifecycle hooks and 44 declared events across five host
  manifests;
- 18 host connector adapters;
- viewer server paths, generic REST proxy status, and literal UI REST
  expressions; and
- all provider adapter classes discovered under `src/providers`.

The starting revision's 115 missing-auth routes are retained in the R-14
pre-fix receipt. The current inventory reaches zero missing protected routes,
but that is remediation evidence only and does not retire R-14.

## Cross-Surface Rules

1. `GET /agentmemory/livez` is the complete public-route allowlist. Detailed
   health is authenticated because it exposes dependency and runtime telemetry.
   Every other REST route requires authenticated middleware.
2. A missing or unreadable server secret makes protected REST and MCP surfaces
   unavailable. It never disables authentication.
3. Project-bound operations require canonical `project`. Global access requires
   an explicit `scope=global` input and an audit event.
   The scope-less `agentmemory://graph/stats` resource is intentionally absent;
   graph reads use the scoped MCP tool or REST route.
4. Strict/local privacy is evaluated before each external-provider attempt.
   Lower-precedence configuration and provider fallback cannot relax it.
5. Context reports each required and optional source outcome. Required-source
   failure is `failed`; allowed optional-source failure is `degraded`.
6. Packet generation, dispatch, acknowledgement, and consumption are distinct
   states. Only a valid acknowledgement suppresses a source for a session.
7. Migration and restore use complete state manifests. A failed operation
   leaves either the pre-operation generation or the target generation.
8. Health distinguishes process liveness, required-backend readiness, pressure,
   compatibility, and recovery windows.
9. Recalled content is advisory. Tests, runtime receipts, commits, live source,
   and accepted external ADRs remain authoritative.

## Denominator Rules

- REST denominator: every generated route. The generator fails `--check` when
  any non-allowlisted route lacks `middleware::api-auth`.
- MCP denominator: all tools returned by `getAllTools()`, including whether
  `project` and `scope` are declared and required, plus transport routes,
  resources, prompts, and standalone fallback tools.
- Hook denominator: every `hookEntries` member in `tsdown.config.ts`, in both
  `dist/hooks` and `plugin/scripts`, plus every declared host-manifest event.
- Provider denominator: every discovered provider adapter plus each query,
  embedding, vision, migration, fallback, and outbound transport attempt site.
- Traceability denominator: every generated surface carries at least one
  control, requirement, risk, and executable test backlink.
- Revision denominator: the inventory records the source commit, committed tree,
  and a SHA-256 digest of every file parsed to generate the denominator.
- Connector denominator: all `ADAPTERS` entries and integration manifests.
- Viewer denominator: explicit server paths, the generic proxy contract, and
  every statically discoverable literal UI REST expression.
- Test denominator: all 147 governed `*.test.ts` files. Omitted or skipped
  mandatory authentication/integration evidence fails the receipt.

## Review Boundary

Configuration Manager signs inventory completeness. Software and Security
Architects review proposed contracts. Test Architect reviews the verification
denominator. Their review does not accept ADRs, baseline architecture, change a
risk status, authorize Construction, or authorize rollout.
