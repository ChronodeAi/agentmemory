# Vision Document

Status: Draft; requires Product Owner/Founder acceptance
Date: 2026-07-25

## Problem

Coding agents need durable project knowledge, but remembered content can be stale, cross-project, secret-bearing, duplicated, or mistaken for current authority. Structural navigation and episodic memory must cooperate without either replacing Git, live source, tests, accepted ADRs, or runtime evidence.

## Vision

Universal Coding Memory Optimization will make Agentmemory a bounded, project-scoped evidence assistant throughout:

`Recall -> Verify -> Explore -> Act -> Test -> Record -> Promote -> Commit -> Close`

It will use Codebase Memory for structural discovery, Agentmemory for episodic/procedural recall, and explicit evidence eligibility to ensure only current, attributable content affects gate-critical work.

## Success

Success requires all numerical acceptance thresholds in the supplemental specification, acknowledgement-backed delivery, usable Codex/Claude integration, recovery/rollback evidence, and a five-session explicit-only Memetics canary. No single unit-test pass or configured hook counts as delivered, healthy, authoritative, or rollout-ready.

## Non-goals

- Replacing source control, tests, accepted ADRs, or live runtime evidence.
- Automatically synchronizing provider-native memory.
- Sharing content between projects through an implicit global namespace.
- Sending strict-privacy content to external processors.
- Distributing the addon or editing Codebase Memory in this repository run.
